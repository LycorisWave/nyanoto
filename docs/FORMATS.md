# Форматы Nyanoto

Состояние на 23.10.2026. Путь для каждого формата выбран так: сначала качество звука, потом поддержка,
потом скорость и нагрузка.

**Платформы.** Linux — проверено вживую. Windows¹ — плеер и все библиотеки собираются кросс-компилятором
(llvm-mingw), на живой Windows пока не проверялись. Android² — работает на телефоне со своим интерфейсом,
но FFmpeg в APK пока нет: форматы с пометкой «FFmpeg» на телефоне не открываются.

**FFmpeg.** Форматы с пометкой «FFmpeg» играют через модуль «Редкие форматы через FFmpeg» (Настройки →
Библиотека, включён). Библиотеки FFmpeg загружаются, только когда встречается такой файл. С плеером
поставляется своя сборка FFmpeg 7.1 (`crates/nyanoto-core/ffmpeg/build.sh`, только аудио, LGPL); без неё в
Linux берётся системный FFmpeg 7 — в Fedora (`ffmpeg-free`) в нём нет E-AC3, WMA Pro/Lossless и DST.

**Оценка поддержки:** **отличная** — эталонный или проверенный бит в бит декодер; **хорошая** — надёжный
декодер, проверен на образцах; **не проверена** — должна работать, но настоящего файла не было;
**слабая** — есть известные ограничения.
