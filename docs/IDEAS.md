# Nyanoto — идеи

Журнал идей. Идея — ещё не решение: всё, что меняет
продукт, сначала согласуется с владельцем проекта. Любая новая
функция — отключаемый модуль, выключенный по умолчанию.

Пометки: **(польз.)** — пожелание владельца проекта, **(предл.)** — предложение
по ходу работы. Статус: *новая*, *согласована*, *в работе*, *сделана*, *отклонена*.

## Форматы

- **(польз.)** Полный набор форматов — «от WAV до Opus и MP3». *согласована; путь — по конституции
  (качество → поддержка → скорость → нагрузка), пользователь 17.10.2026: «следуй конституции».*
  Через Symphonia: FLAC, MP3, AAC/ALAC (M4A), Vorbis, WAV, AIFF, CAF, MKV/WebM.
  Сделано 17.10.2026 (подробно в LOG.md):
  - Opus — эталонная libopus из исходников.
  - WavPack (с файлами коррекции .wvc, плавающей точкой, DSD внутри), Monkey's Audio (все уровни, 8–32 бит,
    плавающая точка, многоканальный) и Musepack SV7/SV8 — эталонные библиотеки из исходников: только они
    читают все разновидности своих форматов бит в бит.
  - TTA и DSD (DSF, DFF) — свой код (TTA проверен бит в бит против кодировщика FFmpeg и на настоящей музыке).
  Осталось:
  - **(предл.)** WMA (в том числе Pro и Lossless), AC3/E-AC3, DTS (в том числе DTS-HD MA), TAK, DST (сжатый DSD в
    DFF), ATRAC и прочая редкость — отдельным **необязательным модулем FFmpeg**: открытых эталонных библиотек
    для них нет, а Windows-кодеки (Media Foundation) — только Windows. Модуль подгружается при включении
    (Linux — системный libavcodec или свой, Windows — DLL рядом с плеером, Android — свой в APK); выключен —
    ничего не тратит. *сделана 18.10.2026 по просьбе пользователя («ffmpeg сделай»); таблица — FORMATS.md*
  - **(предл.)** HE-AAC отдавать FFmpeg (Symphonia умеет только AAC-LC), если проверка покажет, что она играет его глухо. *новая*
- **(предл.)** Свой перевод DST в PCM: FFmpeg распаковывает DST и переводит в PCM своим простым фильтром; можно взять
  у него только распаковку, а в PCM переводить нашим конвертером. *новая*
- **(предл.)** Чтение ReplayGain из заголовка Musepack (сейчас — только из тега APEv2). *новая*
- **(предл.)** Настройка перевода DSD в PCM: частота (88,2 / 176,4 / 352,8 кГц) и срез фильтра (35/50 кГц и
  шире). Сейчас выбрано по качеству: DSD64 → 88,2 кГц с ровной полосой до 35 кГц, DSD128 и выше →
  176,4 кГц до 50 кГц. *новая*
- **(предл.)** DSD «как есть» (DoP или родной DSD) для ЦАП, которые его принимают, — вместе с монопольным
  выводом (сейчас он есть только в Windows). *новая*
- **(предл.)** Переход на Symphonia 0.6.1 (вышла; API другой). Сначала замерить скорость
  декодирования и проверить наши FLAC-тесты (пропавшие кадры, обрезанные файлы). *новая*
- **(польз.)** Конвертация в MP3 и Opus (сейчас только FLAC и WAV). *Opus теперь возможен: кодировщик
  libopus уже собирается вместе с плеером (17.10.2026). MP3 — по-прежнему нужен кодировщик.*

## Энергоэффективность, память, скорость

- **(польз.)** Плеер должен быть очень лёгким: мало памяти, мало процессора, быстрый запуск;
  прогресс запуска — только если он настоящий. *в работе*
- **(польз.)** Растяжение скорости на Rust вместо Signalsmith (C++) — только если это
  быстрее. *новая, нужен замер*
- **(предл.)** «Бюджет» каждого модуля: выключенный модуль не стоит ничего (ни потоков, ни
  таймеров, ни памяти). Проверять тестом/замером, чтобы это не расползалось со временем. *новая*
- **(предл.)** Окно свёрнуто или закрыто в трей — никаких перерисовок и таймеров интерфейса;
  а ещё лучше — окно уничтожается, движок играет один (цель: < 20 МБ памяти при игре в трее). *новая*
- **(предл.)** Больший буфер устройства (cpal `BufferSize::Fixed`), когда не нужна мгновенная
  реакция: звуковая карта и процессор просыпаются реже. Замерить пробуждения в секунду
  (`powertop`/`perf`) до и после. *новая*
- **(предл.)** Режим «экономия»: один переключатель снижает частоту обновления окна до 1 раза в
  секунду, отключает волну и анимации. *новая*
- **(предл.)** Дисковый кэш миниатюр обложек (начинали раньше) + обложки, встроенные в файл.
  Важно: убирает всплески памяти до ~112 МБ при декодировании больших обложек и ускоряет
  открытие исполнителей. Дополнительно — декодировать JPEG сразу уменьшенным (в 2–8 раз).
  *17.10.2026: сделан как эксперимент и замерен (LOG.md). Плюсы: повторный показ 24 мс вместо 856 мс,
  пик памяти 52 МБ вместо 113 МБ. Минус: место на диске ~21 КБ на альбом (потолок 64 МБ).
  Решение пользователя 17.10.2026: оставить, сделать настройкой «Кэш обложек» (вкл. по умолчанию) с
  пунктами «Сохранять кэш на диск» (да) и «Качество кэша» (высокое/среднее/минимальное, по умолчанию
  среднее) и окном-предупреждением, которое нельзя пролистать, как у проверки подлинности. Сделано.
  Обложки, встроенные в файл, и декодирование JPEG сразу уменьшенным — ещё не сделаны.*
- **(предл.)** Релизный файл без отладочных символов (`strip`): меньше размер (34,7 МБ сейчас) и
  быстрее холодный запуск; минус — в отчётах о падениях не будет имён функций. *новая*
- **(предл.)** Запросы к базе и поиск — в фоновом потоке, окно получает готовые строки. *поиск сделан
  18.10.2026; остальные запросы на 200 тыс. треков ≤ 65 мс — пока не нужно*
- **(предл.)** Разобраться, из чего состоят ~60 МБ памяти окна: буферы программной отрисовки на
  HiDPI (2200×1440 — по 12,7 МБ на кадр), разбор всех системных шрифтов (в Linux их 581),
  кэш глифов, пиксели обложек. Возможные шаги: свой встроенный шрифт вместо обхода всех
  системных, отрисовка только изменившихся областей, сброс кэшей при сворачивании. *новая*
- **(предл.)** Буфер звуковой карты побольше и в Windows/Android (в Linux уже 200 мс, см. LOG.md) —
  после замера там. *новая*
